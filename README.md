# Wortweg

Persönliche Sprachlern-App (Englisch, Russisch, Französisch, Koreanisch, Japanisch) von A1 bis B2, für Deutschsprachige.

App öffnen: https://loslus37-rgb.github.io/wortweg/

Auf iPhone/iPad in Safari öffnen und „Zum Home-Bildschirm“ wählen. Auf dem Mac in Safari „Ablage > Zum Dock hinzufügen“.
